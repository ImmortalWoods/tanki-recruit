# tanki-recruit

Поиск игроков и автоматическая отправка приглашений в клан через «Военкомат» Lesta. Для работы аккаунту нужны права на приглашение игроков. Доступны Linux и systemd для автозапуска.

Скрипт использует отдельный профиль Chromium: пароль вводится вручную в окне браузера. Данные аккаунта, включая cookie, хранятся только на компьютере в `~/.local/share/tanki-recruit/`. Не передавайте эту папку другим людям.

## Установка

Нужны Python 3.10+, модуль `venv`, доступ к сети и графическая сессия для входа.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
.venv/bin/python login.py main
```

Войдите в Lesta в открывшемся окне и нажмите Enter в терминале. Проверка входа подтверждает открытие страницы набора, но не права на отправку приглашений. Если Chromium сообщает об отсутствующих системных библиотеках, установите зависимости Playwright для вашей системы.

## Поиск и приглашения

```bash
.venv/bin/python candidates.py                 # только поиск
.venv/bin/python candidates.py --send --limit 5  # отправить до пяти приглашений
```

По умолчанию при отправке действует предел 10 приглашений за запуск. Поиск запрашивает список по страницам отдельно для каждого уровня подбора и за два периода. На сайте нет надёжного общего числа результатов, поэтому поиск заканчивается после трёх пустых страниц подряд. Это эвристика. При повторе страниц или достижении предела запросов работа останавливается с ошибкой.

Критерии меняются в начале `candidates.py`:

```python
MIN_BATTLES = 5000       # минимум боёв за всё время
MIN_WIN_PERCENT = 53     # минимум процентов побед за всё время
MIN_BATTLES_PER_DAY = 5  # минимум боёв в день в среднем за последние 28 дней
```

`PERIOD_DAYS = 28` соответствует фиксированному периоду сайта и его не следует менять без изменения запроса.

Попытки приглашения записываются в `~/.local/share/tanki-recruit/invitations.sqlite3`. Скрипт не повторяет отправку игроку, который уже есть в этой базе, в том числе при неоднозначном результате. При ошибке он останавливается; если сессия истекла, повторите вход. Не удаляйте базу без необходимости: она защищает от повторных отправок.

## Автозапуск в Linux

После ручной проверки установите таймер systemd:

```bash
sh install-systemd.sh
systemctl --user list-timers tanki-recruit.timer
journalctl --user -u tanki-recruit.service -n 100
```

Таймер запускает отправку ежедневно около 09:00 по местному времени, до 10 приглашений за запуск. При ошибке служба пытается показать уведомление через `notify-send`. Для ручного запуска используйте `systemctl --user start tanki-recruit.service`; для отключения — `systemctl --user disable --now tanki-recruit.timer`. После перемещения проекта повторно запустите установщик.

Автоматизация зависит от сайта Lesta: при изменении его API или отсутствии доступа к аккаунту может понадобиться обновление скрипта или повторный вход.
